Importar prova em PDF

O site abre o PDF, separa as questões e monta o banco. As questões entram como imagem recortada do caderno.

1. Arquivo 2. Conferir cortes 3. Gabarito 4. Concluir

Cada linha vermelha marca o começo de uma questão. Clique na página para adicionar um corte que faltou; clique em cima de uma linha para removê-la. Ajuste até que cada bloco seja uma questão.

Digite o gabarito na ordem das questões. Aceita DDDEA BCDEA…, 1-D 2-A 3-D… ou uma letra por linha. Deixe em branco o que não souber.

Confira antes de adicionar ao banco. Ajuste a letra correta onde precisar e remova o que não for questão.

Importar questões

Anexe o arquivo de questões que você recebeu (.json). Tudo é validado antes de entrar no banco. Se preferir, cole o conteúdo do arquivo abaixo.

Obrigatórios: id, materia, tema, habilidade, banca, ano, dificuldade (facil/media/dificil), enunciado, alternativas (2+), gabarito (índice: 0=A, 1=B…). Opcionais: texto_apoio, tipo_apoio, fonte_apoio, resolucao, tags. Neste protótipo a importação vale para a sessão atual; a gravação definitiva virá com o banco de dados.
